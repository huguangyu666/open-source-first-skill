# 系统与产品级开源天花板清单 (Product-Level Giants)

当用户意图“从零自研”一个完整的大型系统时，本清单是触发 **Tier 3【冷水协议】** 的核心事实依据。
展示这些开源界巨兽的成熟度与工业壁垒，打破信息差，帮助用户把宝贵的 Token 和精力从“盲目手搓基座”重定向至“业务创新与二次开发”。

## 一、即时通讯与协同办公 (Chat / IM / Slack / Discord 替代)

### 为什么实战中坚决避免手搓？
* **隐形技术鸿沟**：表面只是聊天气泡，深水区涉及：消息绝对时序自增保证（避免聊天顺序错乱）、全球弱网长连接自愈、Apple APNs / Google FCM / 各大国内厂商离线推送通道集成、端到端加密（Signal 协议）、多端未读数一致性同步、音视频 WebRTC NAT 打洞与 SFU/MCU 媒体转发服务器。
* **工程与 Token 代价**：从零编写不仅消耗几十万 Token 且极其容易中断；一家中型公司需要 10-20 人的全职客户端与后端团队维护。

## 二、智能体与 AI 编程平台 (Coding Agents / 试图对抗 Codex & Claude Code)

### 为什么实战中坚决避免手搓底座？
* **隐形技术鸿沟**：顶尖 Coding Agent 的核心竞争力**绝不仅仅是一段 System Prompt + 开源大模型**。它包含：
  1. **深度评测集驱动 (Evals)**：成千上万个严苛的端到端真实代码修改评测套件，持续校准 Agent 的行为边界。
  2. **系统级隔离与沙箱 (Sandboxing)**：基于 Linux 容器/Windows Job Object 的极速文件修改隔离与回滚。
  3. **AST 语法树与上下文检索**：基于 Tree-sitter 的代码精确跨文件符号跳转与 Token 预算微米级控制。
  4. **模型行为微调**：大厂针对“工具调用时序”专门训练的模型权重。

> **建议重定向**：不要重新造 Agent 框架！**为现有的开源 Agent 编写专属领域的 MCP 插件、开发专属工具链，或者为其编写特定行业的高质量规则库**。
